# Third-party material

The runtime uses only the Python standard library. No third-party implementation
code, datasets or artwork are bundled. Examples are deliberately synthetic.
Standards and competitor documentation informed the design; they were not copied
into the implementation. Python and build/CI tools retain their own licenses.

Development/build tools: Ruff (MIT), build (MIT), setuptools (MIT).
GitHub Actions: actions/checkout (MIT), actions/setup-python (MIT).
These are tooling, not runtime dependencies. CI action revisions are pinned.
